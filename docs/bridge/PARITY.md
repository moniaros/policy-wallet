**Built from the code on NEW-UI `1f863b31` (2026-09-06), not from memory.** Every row names the file that renders the fact on each side. «Can differ» is a code fact; «Should differ» is the product rule (§5 adjudication: the shared object is the truth, depth may differ, fact may not).
